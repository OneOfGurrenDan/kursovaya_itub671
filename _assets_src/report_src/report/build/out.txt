Введение
     Сайт клуба единоборств нужен для простой задачи: человек должен за
минуту понять, что это за клуб, какие в нём тренировки, когда они проходят и
как записаться. Если сайт неудобен, посетитель уходит.
     Цель работы — разработать учебный многостраничный сайт клуба
единоборств GM GYM (Москва) на чистых HTML и CSS, без JavaScript и
библиотек, и описать все этапы работы.
     Задачи:
     1) проанализировать сайты-аналоги (отечественные и зарубежные) и
выбрать решения для своего проекта;
     2) спроектировать сайт: аудитория, структура, дизайн, макет в Figma;
     3)   сверстать   три   страницы:     главную,   страницу   направления
«Бразильское джиу-джитсу (БЖЖ)» с расписанием и формой записи, страницу
«Спасибо»;
     4) проверить результат: валидаторы HTML и CSS, форма, адаптивность,
доступность;
     5) оформить отчёт и оценочный лист.
     Что сделано. Сайт из трёх страниц с общими шапкой и подвалом,
фотографиями (WebP и JPG), видео, формой записи на пробную тренировку,
анимацией при наведении и тремя раскладками для разных экранов. HTML
проходит проверку Nu Html Checker без замечаний. Разработка велась в Git по
веткам: код сайта — [ссылка на GitHub], макет — [ссылка на Figma].
     Это учебный проект, а не официальный сайт клуба. Тексты и
фотографии взяты с сайта клуба [1], описание БЖЖ — из Википедии [8].

1. Анализ аналогов

1.1 Предметная область и выбор темы
     Задание советует не брать слишком узкую тему, а расширить её. Одно
направление, бразильское джиу-джитсу (БЖЖ), — как раз узкая тема: сайт
только про него был бы одной страницей, а для главной и «страницы
конкретного объекта» не хватило бы содержания.
     Поэтому предметная область расширена до клуба единоборств. У клуба
есть главная страница (о клубе, направления, тренеры, контакты) и страницы
конкретных объектов — направлений. Такой страницей в проекте стало
направление БЖЖ (bjj.html): описание, расписание, тренеры, список «что
взять с собой» и форма записи. Остальные направления на главной показаны
карточками. Третья страница, «Спасибо», нужна форме: после отправки
заявки посетитель переходит на неё.
     Выбран реальный клуб GM GYM: Москва, ул. Скаковая, 36, м.
Белорусская, зал 800 м², 8 направлений [1]. У клуба есть действующий сайт,
который можно проанализировать и улучшить. На нём открыты расписание,
тренеры, контакты и фотографии, поэтому тексты и изображения будут по
теме и с указанным источником, а факты можно проверить. Цен на сайте клуба
нет, поэтому в проекте написано «стоимость уточняйте по телефону».
Описание БЖЖ написано по статье Википедии [8].

3.5 Форма записи и переход на страницу «Спасибо»
      На странице БЖЖ есть форма «Запись на пробную тренировку»
(#signup). Посетитель оставляет контакты и выбирает группу, администратор

значением), опыт (переключатели radio) и согласие на обработку данных

комментарий. Код — в листинге 5.

3.6 Анимация
      Анимации короткие (0,25–0,8 с) и нужны для дела: они показывают, что
элемент интерактивный, и не отвлекают. Использовано четыре приёма:
появление первого экрана при загрузке (@keyframes fade-up); плавная
смена цвета и подъём на 2 px у кнопок при наведении (transition); подъём на
6 px и тень у карточек при наведении и при фокусе с клавиатуры; красная
линия под пунктом меню, которая растёт слева направо через ::after
(ширина от 0 до 100 %).

Заключение
     В работе выполнены все этапы задания. Изучены семь сайтов (текущий
сайт клуба, три отечественных и три зарубежных); из анализа взяты решения:
отдельная страница направления с расписанием таблицей, заметная кнопка
записи, форма без всплывающих окон, видео без автозапуска и внимание к
доступности. Спроектированы аудитория и сценарии, структура из трёх
страниц, палитра, шрифты, сетка и компоненты.
     Создан сайт GM GYM на чистых HTML и CSS без JavaScript и
библиотек: главная, страница БЖЖ с расписанием и формой записи, страница
«Спасибо». Есть общие шапка и подвал, фото в WebP и JPG, видео, форма с
проверкой полей и переходом на отдельную страницу, анимация и три
раскладки (ПК, планшет, телефон). HTML и CSS проходят проверку без
ошибок; работа велась в Git по веткам (34 коммитов в 11 ветках).
     Ограничения. Форма не отправляет данные клубу (нет сервера); видео
собрано из фотографий; скринридером доступность не проверялась; макет
Figma выполняется, ссылки на GitHub и Figma предстоит добавить. Что
можно развить: страницы остальных направлений и тренеров, серверная
обработка заявок, карта проезда.
