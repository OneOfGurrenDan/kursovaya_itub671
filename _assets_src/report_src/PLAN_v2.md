## 1. Принцип «просто»: что можно и чего нельзя
Можно, всё это было в лабах:
- семантические теги (header, nav, main, section, article, figure, footer);
- папки css/ и images/, относительные пути;
- CSS-переменные в `:root`, `box-sizing: border-box`, rem;
- **Flexbox** (flex-wrap, gap, justify-content, align-items);
- `position: sticky` у шапки, `scroll-margin-top` для якорей;
- `<picture>` с WebP+JPG, width/height, `loading="lazy"`, `object-fit: cover`;
- ссылки tel:/mailto:, якоря; формы: fieldset/legend, label, required, pattern, type=tel/email, radio, checkbox, select, textarea, submit/reset;
- псевдоклассы :hover, :focus-visible, :invalid; псевдоэлементы ::after (подчёркивание меню), ::selection, ::placeholder;
- transition, transform, box-shadow, linear-gradient, @keyframes;
- @media (max-width), @media (prefers-reduced-motion).

НЕЛЬЗЯ, это лишняя сложность:
- JavaScript в любом виде;
- CSS Grid (в лабах его не было, всё делаем на flex);
- гамбургер-меню на checkbox-хаке (на телефоне меню просто переносится в несколько строк);
- `:has()`, `:user-invalid`, `clamp()`, `@supports`, `forced-colors`, `prefers-contrast`, container queries, srcset/sizes;
- CDN, normalize.css, иконочные шрифты, сторонние библиотеки;
- выдуманные факты, отзывы и цены.

Код короткий и с комментариями на русском: в CSS разделы помечены `/* === Шапка === */` и т.п. Ориентир: style.css ≈ 400–600 строк, каждая HTML-страница ≤ 250 строк.

## 4. Дизайн и доступность
- Палитра в стиле бренда (чёрный, белый, красный): `--black:#111111; --dark:#1C1C1C; --white:#FFFFFF; --light:#F4F4F4; --text:#1A1A1A; --muted:#555555; --red:#D7140A; --red-dark:#A80F07`. Красный используем для кнопок и акцентов, текст на красном белый и жирный. Контраст проверить ≥ 4.5:1 и записать в README.
- Шрифты: Oswald 500/700 для заголовков (uppercase), Roboto 400/700 для текста. Подключение через свой `@font-face` из `fonts/`: npm `@fontsource/oswald`, `@fontsource/roboto`, берём woff2 cyrillic+latin. Базовый размер 16px (1rem), line-height 1.6.
- Тёмные секции (hero, видео, CTA, подвал) чередуются со светлыми (о клубе, направления, тренеры).
- Логотип: `gmgym-logo-black.png` (круглый, чёрный, прозрачный фон). Для тёмной шапки сделать белую версию: инвертировать цвет через Pillow, сохранить PNG ~120px и 240px (для retina). Высота логотипа в шапке ~48px.
- Доступность: `lang="ru"`; skip-link «Перейти к содержанию»; один h1 на странице и логичная иерархия h2/h3; alt у всех содержательных изображений (`alt=""` у декоративных); у полей label; fieldset/legend; видимый `:focus-visible` (outline 3px); контраст AA; таблица с caption/th/scope; минимальная высота кнопок/ссылок меню 44px; `@media (prefers-reduced-motion: reduce)` отключает анимации; в видео нет звука, и это указано текстом.
- Адаптив, ровно 2 медиазапроса:
  - ПК (≥1024): контейнер max-width 1200px, hero в 2 колонки, направления по 4 в ряд, тренеры по 4 в ряд;
  - `@media (max-width: 1023px)` (планшет): по 2 в ряд, hero в одну колонку, меньше отступы и заголовки;
  - `@media (max-width: 767px)` (телефон): по 1 в ряд (тренеры по 2), меню переносится под логотип (flex-wrap, по центру), кнопка «Записаться» во всю ширину, у таблицы горизонтальная прокрутка.
- Анимации (3, все логичные): (1) @keyframes `fade-up` для текста hero при загрузке; (2) transition карточек (подъём translateY(-6px) + тень) и кнопок (смена фона) при hover/focus; (3) подчёркивание пунктов меню через ::after (ширина 0 → 100%). Всё отключается prefers-reduced-motion.
