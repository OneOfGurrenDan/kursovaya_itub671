# GM GYM — учебный сайт клуба единоборств

Курсовая работа по дисциплине «Основы веб-технологий». Тема: «Разработка веб-сайта клуба единоборств GM GYM».
Исполнитель: Смирнов Даниил Алексеевич, группа 251-671, Московский Политех. Принимает: доцент кафедры ИКТ Темникова К.Н. Москва, 2026.

Статический многостраничный сайт на чистых HTML и CSS: без JavaScript, без библиотек и фреймворков.
Все тексты и фотографии по теме клуба (источники ниже). Цены на сайте не указаны, потому что на сайте клуба их нет.

## Как открыть

Дважды щёлкните по файлу `index.html`: сайт откроется в браузере, никакой установки и сервера не нужно.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран, о клубе, направления, тренеры, зал, видео, призыв записаться |
| `bjj.html` | Страница объекта — направление БЖЖ: описание, расписание, тренеры, что взять с собой, форма записи на пробную |
| `thanks.html` | «Заявка отправлена», на неё ведёт форма |

## Структура файлов

```
site/
  index.html          главная
  bjj.html            направление БЖЖ + форма
  thanks.html         заявка отправлена
  css/style.css       единственный файл стилей
  fonts/              Oswald (заголовки) и Roboto (текст), woff2, кириллица и латиница + лицензии OFL
  images/             фото клуба в WebP и JPG, логотип (PNG)
  images/trainers/    карточки тренеров в WebP и JPG
  video/              promo.mp4 (слайдшоу из фото, без звука) и promo-poster.jpg
  README.md           этот файл
```

## Какие приёмы где применены

| Приём | Где |
|---|---|
| Семантические теги `header`, `nav`, `main`, `section`, `article`, `figure`, `footer` | все страницы |
| Одинаковая шапка и подвал, `title` у каждой страницы | все страницы |
| Кликабельное меню, `aria-current="page"` у текущего пункта | шапка и подвал |
| Якоря и `scroll-margin-top` | `#directions`, `#trainers`, `#signup`, `#contacts` |
| Ссылки `tel:`, `mailto:`, `wa.me` | подвал, блок рядом с формой |
| CSS-переменные в `:root` (палитра, шрифты) | начало `style.css` |
| `box-sizing: border-box`, `rem` | раздел «База» |
| Свои шрифты через `@font-face` | раздел «Шрифты», папка `fonts/` |
| Flexbox: `flex-wrap`, `gap`, `justify-content`, `align-items` | шапка, карточки, форма, подвал, колонки |
| `position: sticky` у шапки | `.header` |
| `<picture>` с WebP и JPG, `width`/`height`, `loading="lazy"` | все фото |
| `<video controls muted preload="none" poster>` | главная, секция «Видео» |
| Таблица: `caption`, `th scope="col"` и `scope="row"`, `rowspan` | расписание на `bjj.html` |
| Обёртка таблицы `overflow-x: auto` | прокрутка на телефоне |
| Форма: `fieldset`/`legend`, `label`, `required`, `pattern`, `minlength`, `type="tel"`, `type="email"`, `radio`, `checkbox`, `select`, `textarea`, `submit`/`reset` | `bjj.html#signup` |
| Отправка на отдельную страницу: `action="thanks.html" method="get"` | форма |
| `:focus:invalid` (красная рамка), `:valid:not(:placeholder-shown)` (зелёная) | раздел «Форма записи» |
| `::after` (подчёркивание меню, черта под заголовком), `::selection`, `::placeholder` | `style.css` |
| `transition`, `transform`, `box-shadow` | кнопки и карточки при наведении |
| `linear-gradient` | фон первого экрана |
| `@keyframes fade-up` | появление первого экрана |
| `@media (max-width: 1023px)` и `@media (max-width: 767px)` | три раскладки: ПК, планшет, телефон |
| `@media (prefers-reduced-motion: reduce)` | отключает анимации |
| Ссылка «Перейти к содержанию», `:focus-visible` | доступность с клавиатуры |
| `alt` у всех изображений (у логотипа `alt=""`, рядом текст «GM GYM») | все страницы |

Также используются `calc()` для ширины карточек (например, «четыре в ряд» = `(100% - 3 промежутка) / 4`), `accent-color` у переключателей и `:focus-within` у карточек.

## Проверки

- Валидация HTML и CSS: Nu Html Checker (`vnu.jar --also-check-css`), 0 ошибок и 0 предупреждений.
- Форма проверена в Chromium (Playwright): пустая форма не отправляется, заполненная ведёт на `thanks.html`; телефон «+7 999 123-45-67» проходит, «123» нет.
- Горизонтальной прокрутки нет на ширинах 1440, 768 и 375 px.

## Источники

Фотографии и информация: официальный сайт клуба [gmgym.ru](https://gmgym.ru) (данные на 08.10.2026). Использованы для учебного проекта; права на материалы принадлежат клубу.

| Материал | Источник и обработка |
|---|---|
| Фото зала, ресепшена, зоны отдыха, командное фото | gmgym.ru; обрезаны чёрные поля, уменьшены, сохранены в WebP (качество 80) и JPG (качество 82). Исходные фото небольшие (700–1280 px), поэтому не увеличивались |
| Карточки тренеров (имя и направление нанесены на картинку) | gmgym.ru; WebP и JPG, 450×450 px. Имя и направление дублируются текстом в подписи |
| Логотип | gmgym.ru; для тёмной шапки сделана белая версия (инвертирован цвет, PNG 120 px) |
| Расписание БЖЖ | gmgym.ru, расписание клуба на октябрь 2026 г. |
| Контакты, удобства, список направлений | gmgym.ru |
| Видео `promo.mp4` | собрано из фотографий клуба (ffmpeg, слайдшоу 17.5 с, 1280×720, H.264, без звука) |
| Общее описание БЖЖ | статья «Бразильское джиу-джитсу», Википедия |

Шрифты: [Oswald](https://github.com/googlefonts/OswaldFont) и [Roboto](https://github.com/googlefonts/roboto-classic), лицензия SIL Open Font License 1.1 (тексты лицензий лежат в `fonts/OFL-Oswald.txt` и `fonts/OFL-Roboto.txt`). Файлы woff2 взяты из npm-пакетов `@fontsource/oswald` и `@fontsource/roboto` версии 5.3.0.
